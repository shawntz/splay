{%- comment -%} A table row in Markdown escapes a pipe in code as \|, as GitHub needs. GitHub then shows a plain pipe, but kramdown keeps the backslash in code. So in each table that has one, and only there, turn \| back into a pipe. Each word of the code in such a table also goes into a span that the stylesheet keeps on one line, so a long command wraps only after a space or a pipe.
