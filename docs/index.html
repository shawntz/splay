Splay

A tiling window manager for macOS. Each Space is one row of columns that runs past the edges of the display, and Cmd-Left and Cmd-Right scroll along it.

Splay is a fork of Dinky by Mikkel Malmberg. It makes Dinky's scrolling layout the default and adds column commands modelled on niri. System Integrity Protection stays on.

A row of columns on every Space

A new window opens as a column to the right of the focused one, 0.49 of the display wide, and the other columns keep their widths. Moving focus scrolls the row just far enough to show the focused column whole. Columns out of view hang off the edge with 25 points showing, because macOS can't clip another app's window.

Cmd-Left Cmd-Right
Focus the column to the left or right
Cmd-Home Cmd-End
Focus the first or last column
Alt-J Alt-K
Focus the window below or above in a column
Alt-Shift-H Alt-Shift-L
Swap the column with its neighbour

Column widths from the keyboard

Alt-R steps the focused column through a third, a half and two thirds of the display, and Alt-Shift-R steps back. Alt-M widens it to the whole display, and a second press gives it back its width. Alt-C centres it and keeps it centred while you work in it.

splay column-width 0.75 sets an exact share from a script, and run = 'column-width 0.66' in a window rule opens an app's windows at two thirds.

Focus lands where you left it

Moving into a column lands on the window you last used there, as in niri. When another column closes or changes width, the focused column stays where it is on screen. Windows already open when Splay starts go into the strip left to right, as they stand.

For half a second after Splay focuses a window, or until macOS reports it in front, commands start from that window, so quick presses of Cmd-Right step one column each.

Workspaces are native Spaces

Ctrl-Left and Ctrl-Right switch workspace, Alt-1 to Alt-9 go to one, and Alt-Shift-2 sends the focused window to workspace 2. Each workspace is a macOS Space with a strip of its own.

This part is Dinky's. It switches Spaces with a synthetic Dock swipe and a few private SkyLight calls, so a macOS update can break it.

Splay and Dinky

Dinky is a tiling window manager for macOS by Mikkel Malmberg that leaves System Integrity Protection on. Splay is a fork of it, and almost all of Splay's code is Dinky's, including the scrolling layout, which Dinky added in version 0.16. Splay changes what you get on the first run and adds commands for the strip.

What Splay adds

  • The scrolling layout is the default. default-layout = 'tiles' brings back Dinky's.
  • Cmd-Left and Cmd-Right move between columns, Cmd-Home and Cmd-End jump to the ends.
  • column-width with preset steps or an exact share, maximize-column that remembers the old width, center-column and focus-column. They have keys and menu items, and work from the command line and in window rules.
  • [scrolling] settings for center-focused-column, preset-column-widths and peek.
  • Focus into a column lands on its last used window, and the focused column holds its place when others close or resize.
  • No login item unless you set start-at-login = true.
  • Its own command, config, log and bundle ID, so it can be installed beside Dinky.

What Dinky has that Splay doesn't

  • 30 tagged releases, from v0.1.0 to v0.28, each with a changelog entry.
  • A download and a Homebrew cask.
  • Updates through Sparkle, from its menu.
  • Builds signed with Developer ID and notarized, for Apple silicon and Intel.
  • Use in practice. Its manual says its author uses it daily on macOS 27.
  • Continuous integration, and a fuzzer that drives the running app in a virtual machine and checks the layouts.
  • Fixes land there first. Splay gets them only when they are merged by hand.
  • Cmd-Left, Cmd-Right, Cmd-Home, Cmd-End and Option-R, C and M stay with your apps, and Alt-H and Alt-L focus left and right.

What Splay costs

  • Cmd-Left and Cmd-Right never reach apps while Splay runs. Text fields lose line start and end, where Ctrl-A and Ctrl-E still work, and browsers lose Back and Forward, where Cmd-[ and Cmd-] still work. exclude-apps gives the keys back to the apps you list.
  • The defaults take Option-R, Option-Shift-R, Option-C and Option-M, which type ®, ‰, ç and µ on a US layout.
  • You build it yourself with Xcode 26 or later. Without an Apple Development certificate it signs ad hoc, and each rebuild loses the Accessibility grant.
  • It has been unit-tested on macOS 27 only, and so far has run on one Mac.

Kept from Dinky as they are: the dwindle, fixed and master layouts, workspaces as native Spaces, window rules, the splay command line and socket with AeroSpace-style queries, hooks for bars such as SketchyBar, focus borders, drag and drop, splay doctor, and putting every window back when you quit. 551 of Splay's 696 unit tests are Dinky's.

For the strip in a signed app that updates itself, install Dinky and set default-layout = 'scrolling' in its config. Run one of the two at a time. Splay warns while Dinky is running.

Default keys

Every binding is spelled out in ~/.config/splay/splay.toml, and a bound key never reaches the app in front. Alt is the Option key. The keys marked Splay are new in this fork.

Dinky also binds Alt-H and Alt-L to focus left and right. Splay leaves them unbound, so Option-H and Option-L reach apps and tools such as Hammerspoon. Two lines in [mode.main] bring them back, as Keys in the manual shows.

Build and first launch

  1. Build

    You need Xcode 26 or later, which runs on macOS 15.6 or later. There is no download, and so far Splay has been built on macOS 27 only. 

    git clone https://github.com/shawntz/splay.git
cd splay
scripts/bundle.sh
open build/Splay.app

  2. Allow Accessibility

    Splay asks for Accessibility and waits. Turn it on under System Settings > Privacy & Security > Accessibility. Closing its window before then quits it.

  3. Use the strip

    Once allowed, Splay tiles every open window on screen into the strip, left to right. Quit from its menu bar item and every window goes back where it was. splay doctor checks the config and the macOS settings Splay relies on.

The manual covers signing so the grant survives rebuilds, putting the splay command on your PATH, the two macOS settings Splay asks about, moving over from Dinky, and how to remove Splay and undo what it changed.
