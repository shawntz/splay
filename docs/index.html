Splay

A scrolling tiling window manager for macOS. Each Space is one row of columns that runs past the edges of the display, and Cmd-Left and Cmd-Right walk it.

The niri and PaperWM idea on a Mac, with System Integrity Protection left on. A fork of Dinky, built around the strip.

Get started GitHub

For macOS 15 or later. Build it from source with Xcode 26 or later.

A row of columns on every Space

A new window opens as a column beside the focused one, and the others keep their widths. Moving focus scrolls the row just far enough to show the focused column whole. Columns out of view leave a sliver at the edge, so you can see what is there.

Cmd-Left Cmd-Right
Focus the column to the left or right
Cmd-Home Cmd-End
Focus the first or last column
Alt-J Alt-K
Focus down or up within a column
Alt-Shift-H Alt-Shift-L
Move the column left or right

Column widths from the keyboard

Alt-R cycles the focused column through a third, a half and two thirds of the display. Alt-M maximizes it and a second press restores it. Alt-C centres it.

splay column-width 0.75 sets any share from a script, and run = 'column-width 0.66' in a window rule opens an app at two thirds.

Focus lands where you left it

Go back to a column and you land on the window you last used there. When another column closes or resizes, the one you are looking at stays put.

Fast presses keep up. Each Cmd-Right steps one column, without waiting for macOS to catch up with the last.

Workspaces are native Spaces

Ctrl-Left and Ctrl-Right switch workspace, Alt-1 to Alt-9 go to one, and Alt-Shift-2 sends the focused window to workspace 2. Each workspace is a macOS Space with a strip of its own, and switching skips the slide animation.

Any workspace can use another layout instead: dwindle, master, a fixed grid or an accordion.

Splay and Dinky

Splay is a fork of Dinky by Mikkel Malmberg, and it keeps merging Dinky's changes. Dinky tiles in a dwindle layout by default and offers a scrolling strip as an option. Splay is built around the strip.

While Splay runs, Cmd-Left and Cmd-Right belong to it. In text fields Ctrl-A and Ctrl-E still reach the ends of a line, and in browsers Cmd-[ and Cmd-] still go back and forward. Keys in the manual shows how to hand a key back to an app.

Install

  1. Build

    You need Xcode 26 or later. 

    git clone https://github.com/shawntz/splay.git
cd splay
scripts/bundle.sh
open build/Splay.app

  2. Allow Accessibility

    Splay asks for Accessibility and waits. Turn it on under System Settings > Privacy & Security > Accessibility.

  3. Use the strip

    Once allowed, Splay tiles every open window into the strip, left to right. Quit from its menu bar item and every window goes back where it was.

The manual covers the first run in full, the two macOS settings Splay asks about, moving over from Dinky, and how to remove Splay.
